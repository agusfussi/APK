# 📱 Arduino Detection App

Android application developed as part of an Arduino-based project.

The app is designed to work alongside an Arduino system, providing a mobile interface for interacting with and monitoring the project's detection system.

## 🚀 Overview

This project consists of an Android application and an Arduino-based hardware system.

The Android application provides a simple interface that allows the user to interact with the Arduino project and receive information from the detection system.

The application was created using **MIT App Inventor**, making it easy to develop and prototype the mobile interface while focusing on the interaction between the Android device and the Arduino hardware.

## ✨ Features

- 📱 Android mobile interface
- 🤖 Integration with an Arduino-based project
- 🔎 Detection system interaction
- 📊 Display of information received from the hardware
- 🧩 Simple and accessible user interface
- 🔧 Designed as part of an educational / prototyping project

## 🛠️ Technologies

- **Arduino** — Hardware and detection system
- **MIT App Inventor** — Android application development
- **Android** — Mobile platform
